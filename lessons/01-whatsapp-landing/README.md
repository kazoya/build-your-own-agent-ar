# الدرس 01: صفحة هبوط بزر واتساب

تبني صفحة واحدة. الزر يفتح واتساب على رقمك، والرسالة العربية مكتوبة مسبقاً.

لا إطار عمل. لا حساب مطور. واتساب يفتح عبر الرابط `https://wa.me/`.

## ماذا تحتاج

- محرر نصوص
- متصفح
- رقم واتساب تملكه، بصيغة دولية بلا صفر وبلا علامة زائد داخل الرابط. مثال الشكل: `9627XXXXXXXX`

## ابنها بيدك

1. أنشئ مجلداً اسمه `landing`.
2. داخله ملف `index.html`.
3. الصق الهيكل التالي واستبدل `YOUR_NUMBER` برقمك، وعدّل جملة الرسالة إن شئت.

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>تواصل عبر واتساب</title>
</head>
<body>
  <main>
    <h1>مرحباً</h1>
    <p>اكتب طلبك في واتساب. نرد خلال ساعات العمل.</p>
    <a id="wa" href="#">افتح واتساب</a>
  </main>
  <script>
    const phone = "YOUR_NUMBER";
    const text = "السلام عليكم، أود الاستفسار بخصوص ";
    const link = document.querySelector("#wa");
    link.href = "https://wa.me/" + phone + "?text=" + encodeURIComponent(text);
  </script>
</body>
</html>
```

4. افتح الملف في المتصفح بنقر مزدوج.
5. اضغط الزر. يجب أن يفتح واتساب والنص العربي ظاهراً في خانة الكتابة. لا تضغط إرسال إن كنت تجرّب فقط.

نسخة المرجع، بنفس الرقم الوهمي، موجودة هنا: [index.html](index.html).

## متى ينجح الدرس

- اتجاه الصفحة من اليمين لليسار.
- الزر رابط واحد واضح، وليس صورة فقط بلا نص.
- الرابط يبدأ بـ `https://wa.me/` ثم أرقام فقط.
- النص العربي يظهر في المحادثة بعد الترميز، لا كرموز مكسورة.

## ماذا لا تفعل

- لا تضع رقم شخص آخر.
- لا ترسل الرسالة تلقائياً. الرابط يفتح المحادثة فقط.
- لا تطلب مفتاح API في هذا الدرس.
