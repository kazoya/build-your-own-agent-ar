| المرجع | ماذا نأخذ منه | أين هو هنا |
|---|---|---|
| [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) | كل درس يبني قطعة حقيقية | `lessons/` |
| [developer-roadmap](https://github.com/kamranahmedse/developer-roadmap) | مسار من الصفر حتى التسليم | [ROADMAP.md](ROADMAP.md) |
| [public-apis](https://github.com/public-apis/public-apis) و Awesome lists | قائمة أدوات للسوق العربي | [catalog/free-apis-ar.md](catalog/free-apis-ar.md) |
| [system-design-primer](https://github.com/donnemartin/system-design-primer) و [coding-interview-university](https://github.com/jwasham/coding-interview-university) | تحضير مقابلة تقنية | [interview/README.md](interview/README.md) |
| OpenClaw وأمثالك العاملة | وكلاء من مشاريع حقيقية | [examples/README.md](examples/README.md) |
| [rctc-skill](https://github.com/kazoya/rctc-skill) | المهارات الجاهزة بعد آخر درس | [skills/README.md](skills/README.md) |
