# المهارات الجاهزة

هذا آخر المسار، وليس أول خطوة.

بعد أن تبني الصفحة، ثم مسار الرد، ثم تعرف أين تتوقف للإنسان، استدعِ مهارة بدل إعادة كتابة التعليمات في كل محادثة.

المستودع: [kazoya/rctc-skill](https://github.com/kazoya/rctc-skill)

ابدأ بهذا الترتيب، وهو مكتوب أيضاً في README هناك:

1. `rctc-method` لضبط الطلب.
2. `focused3-agentic-phases` للتفكير ثم التنفيذ ثم الدليل.
3. `safe-forward-execution` حتى لا تتجاوز صلاحيتك.
4. `owner-credential-vault` لأسرارك أنت.
5. `logged-in-browser` إذا كانت نافذة المتصفح مفتوحة ومسجلة دخولاً باسمك.
6. `design-taste-rctc` ثم `design-taste-frontend` إذا كنت تبني واجهة.

حزمة المبرمج اليومية: [programmer-essentials-20](https://github.com/kazoya/rctc-skill/tree/master/packs/programmer-essentials-20).

## تثبيت الحزمة الجاهزة من rctc-skill

بعد ما تخلّص درسًا هنا، ثبّت المهارات الجاهزة بأمر واحد:

```bash
git clone --depth 1 https://github.com/kazoya/rctc-skill.git
cd rctc-skill
npm run install:starter
```

التفاصيل: [skills/INSTALL.md](https://github.com/kazoya/rctc-skill/blob/master/skills/INSTALL.md).
ديمو ٦٠ ثانية: [docs/QUICKSTART_60S.md](https://github.com/kazoya/rctc-skill/blob/master/docs/QUICKSTART_60S.md).
